# The World Today — 18 November 2026

A make.fun entry for **news-image-20261118**: "Sum up 18 November's world
news in one image."

The entry is a newspaper front page for Wednesday, 18 November 2026. The
lead story is Ukraine's strike on the Crimean bridge, with the day's other
big stories below it: Trump in Manila for Quad talks before his China trip,
the US strike on an Iranian launch site, the Siberian plane crash, and the
Canada–China trade deals.

## Files

- `entry.png` — the image (JPEG bytes, 1024×1024, under 1 MiB)
- `main.py` — Python 3.13, standard library only; copies `entry.png` to
  `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`)
- `DOSSIER.md` — the news behind the image, with sources and validation
- `LICENSE` — MIT

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program runs twice with byte-identical output: it is a plain copy, no
network, no randomness.
